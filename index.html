How
Nothing is hand-authored. TowsAttackPhases reads each montage's hit windows and adds 0.05 s of grace on each side. The lock is a live query of the montage position, so hit stop needs no special case.
Buffer
A dodge or guard pressed in the swing plays the moment the lock ends. A jump pressed in the swing is dropped. A cancelled attack keeps the stamina it spent.

Full speed is 500 cm/s. The movement component scales speed while the guard tag is held, so speed comes back the instant the guard drops, however it drops.

Anim
The type links a weapon anim layer, ALI_WeaponLayer, into the body's graph, which supplies idle, locomotion and guard poses. 43 nodachi clips come from 9CG's pack, using the mannequin skeleton with no retarget.
